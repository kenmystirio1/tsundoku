# Tsundoku 積ん読

Personal tracker for manga, anime, comics, books and games. Installable web app (PWA), data in Supabase.

- `index.html` – the app
- `platform.js` – Supabase storage/auth, cover uploads, free metadata sources (AniList, Open Library, Google Books, CheapShark)
- `config.js` – Supabase project URL + publishable key
- `setup.sql` – one-time database setup (run in Supabase SQL Editor)
- `covers/` – covers carried over from the original version
